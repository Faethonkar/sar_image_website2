SAR_images_test — Sample images for object detection

This collection contains representative SAR images you can use to test the object-detection pipeline (ships, small craft, large vessels, aircraft where visible). Images are provided as examples — for production use please supply your own SAR imagery with appropriate licensing.

Best suited images: medium-to-high resolution SAR scenes (1–10 m), minimal compression artifacts, with ships visible as bright point-like returns or elongated streaks. Avoid extreme speckle or very low resolution.

Download SAR_images_test.rar and then upload it using the Test SAR Model form above to run detection against the sample dataset.
